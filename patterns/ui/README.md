# Pattern: UI Patterns

Reusable UI implementation patterns.

## Available Patterns (to be implemented)

- **Auth Flow** - login, register, forgot password, OTP verification
- **Dashboard Shell** - sidebar + header + content layout
- **Data Table** - sortable, filterable, paginated data display
- **Search/Filter** - search with faceted filters
- **File Upload** - drag & drop with progress
- **Empty State** - informative empty state with call to action
- **Loading State** - skeleton loaders and spinners
- **Error State** - error boundaries with retry

## Pattern Structure

Each pattern should include:
- When to use
- Files created
- Configuration options
- Test strategy
- Removal strategy
