# Pattern: AI Patterns

Reusable AI implementation patterns.

## Available Patterns (to be implemented)

- **Chat** - conversational AI interface
- **Structured Extraction** - extract typed data from unstructured text
- **Document Analysis** - analyze and summarize documents
- **RAG** - retrieval-augmented generation
- **Recommendation** - AI-powered recommendations
- **Classification** - text/image classification
- **Tool Calling** - AI with typed tool access
- **Agent** - bounded agent with tool permissions
- **Approval Workflow** - human-in-the-loop for dangerous actions
